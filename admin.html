Cómo crear el token (una sola vez)
  • GitHub → foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  • Nombre: «Tablero microáreas». Expiración: la que prefieras (ej. 1 año).
  • Repository access: Only select repositories → elegí el repo del tablero.
  • Permissions → Repository permissions → Contents: Read and write. Nada más.
  • Generar, copiar el token y pegarlo arriba. No lo compartas: con él se puede modificar ese repo.
  • Si no querés usar token: «Copiar data.json», creá/editá el archivo data.json en el repo, pegá y «Commit changes».

Cómo se calcula cada indicador
  • Ventas = contratos de Central con fecha de activación en el mes y con equipo de venta (archivo Activados). Las activaciones sin equipo de venta (transferencias de titular y similares) no cuentan.
  • Churn = contratos de Central cancelados o rescindidos en el mes, por fecha de cancelación (archivo Cancelados). Los transferidos no cuentan. Involuntario = motivo «Falta de Pago»; voluntario = cualquier otro motivo.
  • Base activa = cartera completa de Central: contratos Activos + Bloqueados del export ContratoInfra, con el POP que informa la red. Es una foto: no cambia con el período.
  • Neto = ventas − churn.
  • POP = base: POP de la red (ContratoInfra). Ventas y churn: OS de instalación / última OS del contrato; si no hay, POP de Infra. Sin OS: POP dominante de la ciudad (≥85%); si no, SIN POP. POP con menos de 100 OS van a OTROS POP.
  • Puntaje = (peso ventas × % de ventas + peso base × % de base + peso churn × % de churn) ÷ suma de pesos. Los % son la participación del POP en el total filtrado. Un churn alto sube el puntaje: el ranking mide cuánto representa cada microárea, no qué tan bien le va.
  • Demanda de OS: export Relatorio Suportes, OS de Soporte, Instalación, Comercial (cambio de domicilio, repetidor/extensor, cambio de lugar de ONU) y Negociación (reconexión), por fecha de creación. Se excluyen Retiradas, Planta Externa y Entregas. «Excluir canceladas» quita las OS en estado Cancelado.
  • Comparación: mismo número de meses inmediatamente anterior. Verde = mejora, rojo = empeora (más churn es peor).
